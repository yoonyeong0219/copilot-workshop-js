# 요구사항 — 리스 견적 기능 추가

## 배경

지금은 일시불 견적만 계산할 수 있습니다. 영업 현장에서 리스 문의가 늘어 월 납입금을 함께
안내해야 한다는 요청이 들어왔습니다.

## 요청 내용

기존 견적 결과를 받아 **리스 월 납입금**을 계산하는 기능을 추가해 주십시오.

- 계약 기간은 **36, 48, 60개월** 중 하나를 고릅니다.
- **선수금**은 견적 총액의 일정 비율로 먼저 냅니다.
- 계약이 끝나는 시점의 **잔존 가치**를 뺀 금액을 계약 기간으로 나눕니다.
- 월 납입금은 원 단위로 반올림합니다.
- 계산 결과를 `src/demo.js` 에서도 출력해 주십시오. 지금은 견적만 나옵니다.

## 알려진 기준값

| 계약 기간 | 잔존 가치 비율 |
|---|---|
| 36개월 | 55% |
| 48개월 | 45% |
| 60개월 | 35% |

선수금 비율은 고객이 정하며, 0%에서 30% 사이입니다.

## 확인이 필요한 부분

요구사항이 전부 정해져 있지는 않습니다. 애매한 부분은 **직접 판단해서 구현하지 말고,
계획 단계에서 먼저 드러내 주십시오.**

- 이자나 수수료를 반영해야 하는지
- 선수금이 범위를 벗어나면 어떻게 처리할지
- 기존 `calculateQuote`를 고쳐야 하는지, 새 모듈로 분리해야 하는지
